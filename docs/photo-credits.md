# Photo credits

The carousel on Home (`src/app/data/slides.js`) uses five photographs of two parents with a newborn.
They were chosen and supplied by the team and are saved in `public/slides/`.

| File | Used for |
| --- | --- |
| `hand-it-back.jpg` | "You don’t balance parenthood alone…" |
| `showing-up.jpg` | "Support is not showing up when it’s convenient…" |
| `tap-out.jpg` | "Strength is not doing it alone…" |
| `ask-for-help.jpg` | "Asking for help isn’t losing…" |
| `together.jpg` | "You’re allowed to struggle and still be doing this right — together." |

The source and licence of these five photos are not recorded here. For a class project shown inside
the course this is usually fine, but if the app is ever published, check each photo's licence, and if
one needs a credit, add a `credit` entry for it in `slides.js` and a row above. `tap-out.jpg` is 743
pixels wide, so it looks a little soft on large or high-density screens.
